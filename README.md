# 🩸 Blood Donation Prediction & Healthcare Analysis

## 📌 Project Overview

This project focuses on analyzing blood donation data and building a Machine Learning model to predict blood donation-related outcomes using healthcare data.

The project includes complete data preprocessing, exploratory data analysis (EDA), feature scaling, model training, evaluation, cross-validation, feature importance analysis, and a basic healthcare recommendation system.

The main objective of this project is to use Machine Learning techniques to analyze medical data and generate meaningful predictions and recommendations.

This project demonstrates practical skills in:

* Data Cleaning
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Machine Learning
* Data Visualization
* Model Evaluation
* Cross Validation
* Healthcare Data Analysis
